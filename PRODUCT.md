# Product

## Register

product

## Users
Arabic readers, researchers, and publishers using desktop browsers to prepare books and documents without uploading private files.

## Product Purpose
Provide focused, client-side document utilities as standalone HTML pages. Each tool should complete one practical conversion or cleanup task with minimal setup and explicit output controls.

## Brand Personality
Quiet, direct, trustworthy.

## Anti-references
No SaaS dashboard, decorative landing page, account flow, hidden automation, or unfamiliar document controls.

## Design Principles
- Keep user files local to the browser.
- Make the primary task obvious and linear.
- Show automatic decisions before irreversible output.
- Prefer familiar browser and document controls.
- Explain important output limitations honestly.

## Accessibility & Inclusion
Target WCAG AA with keyboard-operable controls, visible focus, sufficient contrast, status announcements, reduced-motion support, and interfaces that work naturally with Arabic RTL content.
